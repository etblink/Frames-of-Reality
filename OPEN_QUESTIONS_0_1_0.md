# Open Questions 0.1.0

**Status:** pre-inception question set  
**Rule:** questions are not commitments

1. What should the player actually do minute to minute?
2. What makes the game fun independently of its philosophical themes?
3. What kind of open world best supports conflicting frames of the same events?
4. Should there be one protagonist, multiple protagonists, or a player-created character?
5. How much of the underlying world state should ever become knowable?
6. How can the game distinguish uncertainty from arbitrary writer withholding?
7. How should factions model belief, incentives, loyalty, and information?
8. Can rumors and propaganda propagate systemically rather than only through scripted missions?
9. How can the player manipulate information without turning the game into a menu-driven abstraction?
10. What consequences should attach to being wrong for good reasons versus right for bad reasons?
11. Can the game model correction, repentance, or changed beliefs in a meaningful way?
12. How can moral structure remain substantive without becoming a visible morality meter?
13. What does "subtle Christian structure" mean in actual design terms, if it survives later design work?
14. How should satire remain fair enough that the game does not merely reward the creator's preferred faction?
15. What objective facts must the simulation track beneath character interpretations?
16. Which apparent connections to ISR or other projects are genuine design value, and which would be distracting over-intellectualization?
17. What is the smallest prototype capable of demonstrating the core frame-versus-reality mechanic?
